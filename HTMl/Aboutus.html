Who We Are

Student Event Management System

The Student Event Management System (SEMS) is a web-based platform developed to simplify the planning, approval, organization, and participation of college events. It provides an efficient way for students, event hosts, and administrators to collaborate through a centralized system.

SEMS allows event hosts to submit event proposals, enables administrators to review and approve requests, and provides students with an easy way to explore and register for upcoming events. Our goal is to create a transparent, organized, and user-friendly event management experience.

How SEMS Works

SEMS follows a simple workflow that connects event hosts, administrators, and students through one centralized platform.

Submit Proposal

A student fills out the Become Host form with the event details and estimated budget.

Admin Review

The administrator reviews the proposal and decides whether to approve or reject it.

Host Access

Once approved, the host receives login credentials for the Host Dashboard.

Create Event

The host creates and publishes the event with complete information.

Student Registration

Students browse available events and register online to participate.
